Mac 资料设置

所有课程共用一个快捷指令。本环境无法生成、签名或验证可导入的 .shortcut 文件，请按以下步骤创建；无需下载第三方工具。

  1. 在 Mac“快捷指令”中新建一个快捷指令，名称必须是 My Home 打开资料。如已有这个名称的通用快捷指令，可直接检查其设置。
  2. 添加“运行 Shell 脚本”（Run Shell Script）动作：Shell 选择 /bin/bash；“输入”选蓝色变量 快捷指令输入（Shortcut Input），类型设为文本；“传递输入”选作为参数（as arguments）。关闭“作为管理员运行”。将下方完整脚本粘入脚本框。不要把输入变量插入脚本文本，也不要添加“询问输入”“选择文件夹”或成功通知。输入为空时保持不提供输入，不设置为询问。
  3. 如脚本无法运行，在“快捷指令 → 设置 → 高级”开启“允许运行脚本”。
  4. 在本页编辑“资料”，选择“本地资料文件夹”，填写 Mac 路径。Finder 选中文件夹后可按 ⌥⌘C 复制路径。网站保存原始路径，不用自己编码。
  5. 首次请在普通 Safari 窗口点击“测试打开”。若打开快捷指令应用的提示提供“始终允许”，请选择；快捷指令请求必要数据访问权限时也选择“始终允许”。不同 Safari / macOS 版本的提示可能不同，请按实际弹窗授权。
  6. 确认 Finder 中打开的是目标文件夹后，在编辑窗口点击“保存”。以后逐门课程填写路径即可，共用此快捷指令。路径不存在、权限拒绝或打开失败由快捷指令提示；成功时没有额外弹窗。

“测试打开”只发出请求，网页不能确认安装、授权或打开结果。手机和平板不支持此 Mac 文件夹方案。课程标题复用这一条资料快捷指令，完成后通过系统回调打开笔记；不需要另一条课程快捷指令。

如果“打开资料”也弹出或导出 stdout：在 Run Shell Script 后添加 Nothing 动作，再添加 Stop and Output，输出选 Nothing，If there’s nowhere to output 选 Do Nothing。不要将 Script Result 交给 Save File、Open File 或 Quick Look。已能正常打开且没有输出文件时，无需修改。
